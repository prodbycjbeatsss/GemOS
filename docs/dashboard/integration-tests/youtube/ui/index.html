Automatic 24-hour capture setup

The five-minute background checker needs one Google Cloud Scheduler job. Until it is connected, Sync can capture a Short during its 24h–24h15m window.

Download the private job configuration, upload it to Google Cloud Shell in your existing project, then run the commands below. Google may require a billing account; the first three Scheduler jobs per billing account are free.

gcloud services enable cloudscheduler.googleapis.com
gcloud scheduler jobs create http gemos-youtube-capture --location=europe-west2 --flags-file=gemos-scheduler.json
gcloud scheduler jobs run gemos-youtube-capture --location=europe-west2

Check the job's execution succeeds, then Sync the release to see the latest checker status. Keep the downloaded configuration private.
